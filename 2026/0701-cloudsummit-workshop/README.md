## 議程簡介

本場 90 分鐘工作坊帶你動手打造專屬的 AI 工作流，核心是兩大支柱：以 Agent Skill 擴充 AI 的專屬能力，並透過 MCP（Model Context Protocol）讓 AI 串接外部工具與資料來源。從零開始，逐步組裝出一條可重複使用、貼合自身工作情境的自動化流程。

## 議程結構

### 第一部分：Agent Skill 基礎

- Agent Skill 的概念與運作機制
- 撰寫第一個自訂 Skill
- 將領域知識封裝成可重用能力

### 第二部分：MCP 實戰

- MCP 的架構與核心概念
- 串接外部工具、API 與資料來源
- 組合多個 MCP Server 擴展 AI 能力

### 第三部分：組裝你的 AI 工作流

- 結合 Agent Skill 與 MCP 打造端到端流程
- 依自身工作情境調整與擴充
- 常見陷阱與最佳實踐

## 前置需求

- 自備筆電
- 任意支援 Agent Skill / MCP 的 AI 工具帳號（如 Claude Code）
- 基本命令列操作能力
