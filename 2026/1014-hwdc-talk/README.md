## 議程簡介

兩年之內，公司內部的 AI Agent、MCP Server、CLI 工具與自動化腳本數量成長了數十倍。每一個新工具要存取公司資源，都需要「登入」與「授權」——而當認證各自為政，風險與維護成本會跟著一起飆升。

本場分享三個被 AI 自動化放大的資安風險：認證各自造輪子、金鑰隨程式碼推上 Git、Token 發出去就失控；並提出一個觀念轉變——把「機器身分（Machine Identity）」當成一等公民治理。接著以開源認證閘道（OAuth 2.0 / OIDC）為例，拆解 Device Flow + PKCE、帳號來源集中管理，以及 Token 生命週期治理（可查詢、可設到期、可即時撤銷）。
